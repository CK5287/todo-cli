# Todo CLI

A command-line todo list that saves tasks to a JSON file.

## Usage

```bash
python3 todo.py add "Buy milk"         #add a task
python3 todo.py list                     #show all tasks
python3 todo.py done 1                   # mark task 1 as done
python todo.py delete 1                  #delete task 1 (only if it's done)

```
